Completar cuadrados paso a paso

Ejemplo del apunte: reducir 4x²+9y²−8x+36y+4=0.

1. Agrupar

4(x²−2x)+9(y²+4y)+4=0

2. Completar cada cuadrado

4[(x−1)²−1]+9[(y+2)²−4]+4=0

3. Reorganizar

4(x−1)²+9(y+2)²=36

4. Normalizar

(x−1)²/9+(y+2)²/4=1

5. Interpretar

Elipse con centro (1,−2), semieje mayor 3 paralelo a x y semieje menor 2 paralelo a y.
